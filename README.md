# Simple Backend Server

A simple backend server built with Node.js and Express as part of my AI Backend Engineering Bootcamp.

## Technologies Used

- Node.js
- Express.js

## How to Run the Project

1. Install the project dependencies:

   npm install

2. Start the server:

   node server.js

3. Open your browser and visit:

   http://localhost:3000

## Available Endpoints

### GET /

Returns a simple message confirming that the backend server is running.

### GET /about

Returns JSON containing basic information about the project and developer.

## Purpose

This project demonstrates the basic concepts of backend development, including creating an Express server, defining routes, handling HTTP GET requests, and returning text and JSON responses.
